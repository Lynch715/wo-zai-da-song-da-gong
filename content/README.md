# 白话叙事母稿

`prose.cjs` 保存70桩案件的开场、结案、错断后果，新增案的三人供词，五幕主线及69条街闻。`dialogue.cjs` 保存人物交往、开局、结局、店铺叙述和规则文字的改写。

文风采用连贯的白话叙述：先让人物在具体处境里开口，再展开事情经过。对白按职业、性情和交情区别，保留生活细节与适量幽默；少用截断的短句、整齐排比和每案必有的警句。按钮、费用、收益和操作提示保持简洁。

案件开场只给当时可知的情形；调查所得的物证、见证、凭单仍按原线索顺序揭示。叙事细节不充当新的解案证据，结案解释须与已收录线索相合。统一用“你”叙述玩家行动，供词可按人物身份称呼沈捕头、官人或砚哥。

在项目根目录执行以下命令，可将母稿嵌入 `game.html` 与 `index.html`：

```sh
node qa/apply-prose.cjs
node qa/leisure-regression.cjs
node qa/prose-regression.cjs
```

两个游戏入口仍可单文件运行，不会在浏览器中加载母稿或Node模块。文案编译可以重复执行。案件规则基准保存在 `qa/prose-baseline.json`，用于核对身份、答案、奖励、线索数量、矛盾位置与取材来源。
