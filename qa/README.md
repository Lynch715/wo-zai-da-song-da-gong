## v1.4.3 难度收紧（2026-10-13）

审计发现：首章里推理不影响胜负。原版用机器人各跑100～150局（固定种子），一条线索就乱猜的打法（错2/3）仍100%还清，中位第20日，比认真推理（中位第23日）还快；把主线做完则不论还了多少钱都能销债。日常阶段口碑≥60、眼力≥5时，同一时段内可连办40案，赚340贯而时辰不动。

改动（数值与案件内容不变，CASE_BONUS仍为1.25）：
- 小案和主线指认错误不再发半赏，赏钱为零；小案错断后，下一份案卷多等一日。
- 线索未查全就指认，拿对也只发七成赏钱。
- 当堂对质与吴师爷过目共用一次排除，最多洗清一人，剩下两人须靠线索判断。
- 每个时段最多接一桩新案，口碑高时的“免冷却”不能在同一时段反复刷案。
- 第20日还款节点失约，主线第五幕“金满堂罪证”无法递状，只能照常还债；按期还上则不受影响。

- 日常新案的关键线索不再总在第三条：树下羊皮、青菜墨字、鹿脯换签、雪夜木栏、瓦袋换骡、匿名诬状、地窖古钱、高田报涝8案把它挪到第二条（矛盾位置随之为第2条），其余12案仍在第三条。只挑对质台词不依赖原第二条线索的案子，线索文字未改；`prose-baseline.json` 的矛盾位置同步更新。
- 日常阶段恶名过高仍会御史查访、毁证失手入狱并清档，按设计保留。

机器人模拟（`node qa/balance-sim.cjs game.html <打法> 100`，只办案、打工，不行商、不入股、不走灰路）：

| 打法 | 原版还清率 | 现版还清率 |
|---|---|---|
| 全知、每案过堂（honest） | 100%（中位第23日） | 100%（中位第23日） |
| 约两成看错，推主线（cmain） | 100% | 79% |
| 约两成看错，只办小案（careless） | 87% | 33% |
| 两条线索后排除再猜（blind） | 100% | 3% |

真人还可行商、入股、做灰活，实际通关率会高于表中只办案打工的数字。若嫌仍偏松，可再把 `CASE_BONUS` 降到1.1：全知打法中位第25日还清，careless降到18%。

验收：原22组日常回归、文案回归3组均通过；新增 `node qa/difficulty-regression.cjs` 5组；`apply-prose.cjs` 重跑后输出不变；两个入口字节一致。本次备份为 `*.bak-v1.4.2-before-difficulty`。仅做Node验收，未做浏览器与真人试玩。

## 可重复回归

在项目目录运行：

```sh
node qa/leisure-regression.cjs
```

该脚本用Node VM加载实际HTML内的脚本，使用最小DOM与存储桩、固定随机值；检验状态与结算，不代表真实浏览器或真人好玩验收。

`browser-fixture.html` 是本机浏览器场景夹具，iframe加载实际游戏文件。通过界面按钮准备还债、新案、店铺、第30日和隐藏成功路线，可快速验收，不能替代正常完整游玩。
